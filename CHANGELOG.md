## [0.1.0] - 2026-10-24

### Added

- Responsive layouts for home, section, article, taxonomy, and error pages.
- Configurable identity, palette, menus, homepage content, social links, and footer.
- Automatic light and dark modes with a manual three-state theme control.
- Project cards, status labels, tags, reading time, table of contents, pagination, RSS, and social metadata.
- Keyboard navigation, visible focus states, reduced-motion support, print styles, and no-JavaScript fallbacks.
- Example Spudlab site and GitHub Pages deployment workflow.
- Installation, configuration, customisation, and accessibility documentation.
